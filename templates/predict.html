How to Use BarakoSense

Quick guide to get started

1

Upload or Capture an Image

Click to select an image, drag and drop, or use your camera to capture a photo of a Coffea Liberica (Kapeng Barako) tree part. Make sure the image is clear and well-lit for best results.

2

Select Plant Part Type

Choose what type of plant part your image contains from the checklist:

  • Leaf - Image contains only leaf
  • Bark - Image contains only bark/stem
  • Cherry - Image contains only coffee cherries
  • Mix - Image contains multiple parts (ensemble voting)
3

Get Results

Click "Start Prediction" and our AI will analyze the image. If you selected a specific part, only that model will be used. If you selected "Mix", all models will vote on the result.
