# BarakoSense - Coffee Liberica Authenticity Classifier

--- updating

## **Pre-requisites**

### 1. Node.js

- Go to https://nodejs.org
  
- Click the “Latest” version (not LTS).

- Install it — keep all defaults checked.

---

## **Setup Instructions**

### 1. Clone the Repository

```bash
git clone https://github.com/kylajamito/BarakoSense
cd BarakoSense
```

---

### 2. Install Node Packages

```bash
npm install express mysql2 cors multer dotenv
```

---

### 3. Runserver with

```bash
node server.js
```
